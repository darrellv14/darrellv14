# GitHub Achievement Plan for darrellv14

Panduan ini fokus ke achievement yang masih realistis didapat dari aktivitas normal di GitHub. Jangan spam issue/PR di repo orang lain; pakai repo pribadi untuk eksperimen, dan pakai kontribusi asli untuk badge yang sifatnya komunitas.

## Fast Track, Bisa Dikerjakan Hari Ini

### Quickdraw

Target: tutup issue atau pull request kurang dari 5 menit setelah dibuat.

Langkah aman:
1. Buka repo pribadi, misalnya `darrellv14-achievement-lab`.
2. Buat issue berjudul `Quickdraw test`.
3. Langsung close issue tersebut sebelum 5 menit.

### Pull Shark

Target: punya pull request yang di-merge. Beberapa daftar komunitas menyebut base badge muncul setelah 2 merged PR.

Langkah aman:
1. Di repo pribadi, buat branch baru.
2. Ubah file kecil seperti README.
3. Push branch, buka pull request.
4. Merge PR.
5. Ulangi satu kali lagi kalau badge belum muncul.

### YOLO

Target: merge pull request tanpa review.

Langkah aman:
1. Pakai repo pribadi tanpa branch protection yang mewajibkan review.
2. Buat PR kecil dari branch baru.
3. Merge sendiri tanpa meminta review.

Catatan: ini cocok untuk repo latihan, bukan repo production.

### Pair Extraordinaire

Target: co-authored commit yang masuk lewat PR yang di-merge.

Langkah aman:
1. Buat branch baru di repo pribadi.
2. Commit dengan trailer co-author yang valid:

```bash
git commit -m "docs: add co-authored profile update" -m "Co-authored-by: Nama Teman <email-teman@example.com>"
```

3. Push branch, buka PR, lalu merge.

Catatan: gunakan email GitHub teman yang benar dan minta izin dulu. Untuk bot, Anda bisa pakai co-author bot yang memang publik, tapi badge ini lebih bermakna kalau kolaborasinya nyata.

## Medium Track

### Galaxy Brain

Target: jawaban Anda di GitHub Discussions ditandai sebagai accepted answer. Beberapa daftar komunitas menyebut base badge setelah 2 accepted answers.

Langkah:
1. Cari repository yang memakai GitHub Discussions.
2. Jawab pertanyaan yang memang Anda pahami.
3. Jika maintainer/original poster menandai jawaban sebagai answer, progres badge bertambah.

### Starstruck

Target: repository publik Anda mencapai minimal 16 stars untuk base badge menurut daftar komunitas.

Langkah:
1. Rapikan satu project yang benar-benar berguna.
2. Tambahkan README, screenshot, demo, dan instruksi install.
3. Pin repo di profile.
4. Bagikan secara wajar di komunitas yang relevan.

## Program / Highlight Badges

### PRO

Target: akun GitHub Pro. Untuk mahasiswa, coba daftar GitHub Student Developer Pack.

Langkah:
1. Siapkan email kampus atau dokumen mahasiswa.
2. Daftar lewat GitHub Education.
3. Setelah approved, benefit GitHub Pro biasanya aktif di akun.

### Public Sponsor

Target: sponsor open source contributor lewat GitHub Sponsors.

Langkah:
1. Pilih maintainer/proyek yang memang ingin Anda dukung.
2. Sponsor lewat GitHub Sponsors jika tersedia.
